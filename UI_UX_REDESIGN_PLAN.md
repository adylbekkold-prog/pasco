# PASCO Lab Portal — UI/UX Redesign Plan

## Цель

Сделать интерфейс уровня production: единая дизайн-система, чистая навигация, адаптивность для планшетов/телефонов, понятные состояния загрузки/ошибки/успеха и безопасная интеграция без риска сломать SPARKvue.

## Визуальная система

- **Стиль:** чистый образовательный SaaS: Linear/Notion-подход, много воздуха, понятная иерархия, минимум визуального шума.
- **Основной цвет:** глубокий синий `#1d57c8` / dark accent `#60a5fa`.
- **Акценты:** зелёный для успеха, янтарный для предупреждений, красный для ошибок.
- **Темы:** светлая и тёмная через `data-theme` на `<html>`, без внешних запросов.
- **Шрифт:** локальный системный стек с приоритетом `Inter`; Google Fonts не используется.
- **Компоненты:** `Button`, `Input`, `Badge`, `Skeleton`, `MetricCard`, `ToastProvider`, `ThemeToggle`.

## Что уже внедрено

- `ThemeProvider` с сохранением темы в `localStorage`.
- `ThemeToggle` для админки и страницы входа.
- `ToastProvider` и `useToast()` для уведомлений успеха/ошибки.
- `Skeleton` вместо простых серых блоков в админской загрузке.
- `MetricCard` для профессиональных KPI-карточек.
- Обновлённый админский shell с тёмной темой, мобильным меню и улучшенной боковой панелью.
- Обновлённый дашборд: KPI, быстрые действия, активность за 7 дней.
- Улучшенный список лабораторных: поиск через query-параметры, фильтры статуса, адаптивные метрики.

## Страницы

### Админ-дашборд

- KPI: всего лабораторных, опубликованные, черновики, школы.
- Быстрые действия: создать лабораторную, открыть список, школы, результаты.
- Мини-график активности за 7 дней без тяжёлых chart-зависимостей.
- Последние лабораторные с действиями просмотра/редактирования.

### Лабораторные работы

- Поиск по названию/описанию/предмету/классу.
- Фильтры: все, опубликованные, черновики.
- Мобильные карточки и desktop-таблица.
- Горизонтальный скролл таблицы сохранён.

### Дальше к внедрению

- Многошаговый мастер создания лабораторной.
- Статистика по школам/группам/ученикам.
- Профиль пользователя.
- Улучшенный student flow с прогрессом, статусами и draft-save.

## Адаптивность

- **Desktop:** фиксированная боковая навигация, широкие таблицы, KPI-сетки.
- **Tablet:** сетки `2 колонки`, крупные tap-targets, SPARKvue/PDF области без горизонтального ломания.
- **Mobile:** верхняя панель + выдвижное меню, карточки вместо таблиц, кнопки минимум `44px`.

## Безопасность и SPARKvue

- Не менять offline-guard, bridge, CSP и маршруты `/sparkvue/*`, `/uploads/*`, `/whatsnew/*` без отдельного smoke-теста.
- Тяжёлые вьюеры SPARKvue/PDF/video держать лениво загружаемыми и открывать только один активный viewer.
- Админка остаётся скрытой за `/sersdp` и `ADMIN_PASSWORD`.

## Рекомендуемые пакеты для следующего этапа

Уже есть: Tailwind CSS, Radix/shadcn-подход, Lucide React.

Опционально добавить позже:

```bash
npm install framer-motion recharts @dnd-kit/core @dnd-kit/sortable next-themes
```

Важно: добавлять эти зависимости только когда есть интернет/доступ к npm и после проверки `npm run build`.

## План внедрения

1. Довести дизайн-токены и dark-mode для всех старых CSS-классов.
2. Перенести админские таблицы/карточки на единые `MetricCard`, `TableShell`, `EmptyState`.
3. Сделать настоящий view-toggle таблица/карточки с сохранением в query/localStorage.
4. Реализовать wizard создания лабораторной без изменения server actions.
5. Добавить статистику школ и экспорт CSV/PDF.
6. Протестировать tablet/mobile, особенно страницы лаборатории и `.spklab`.
7. Запустить `npm run lint`, `npm test -- --runInBand`, `npm run build`.

## Критерии качества

- Нет внешних запросов для шрифтов/темы.
- Все интерактивные элементы имеют keyboard/focus states.
- Нет зависшей загрузки: skeleton/empty/error-state везде.
- На планшете элементы не меньше `44px`.
- UI не ломает бизнес-логику, локализацию, `/sersdp` и SPARKvue offline.
