# Фотогалерея лабораторных работ (Lab Photo Browser)

## Описание

Новая функция позволяет администраторам удобно выбирать фотографии из организованной иерархии папок при создании лабораторной работы.

## Структура папок

Фотографии организованы в папке `lab_photos/` по предметам:

```
lab_photos/
├── Физика/
│   ├── Механика/
│   │   ├── photo1.jpg
│   │   ├── photo2.jpg
│   │   └── ...
│   ├── Электричество/
│   │   └── ...
│   └── ...
├── Химия/
│   ├── Органическая/
│   │   └── ...
│   └── ...
└── Биология/
    └── ...
```

## Компоненты

### API Endpoint: `/api/lab-photos`

**Route:** `app/api/lab-photos/route.ts`

**Метод:** GET

**Параметры:**
- `path` (optional): путь к папке внутри `lab_photos/` для получения содержимого подпапки

**Ответ:**
```typescript
{
  success: boolean
  data?: {
    name: string
    path: string
    isDirectory: boolean
    children?: PhotoNode[]
  }
  error?: string
}
```

**Пример использования:**
```bash
# Получить корневую структуру
GET /api/lab-photos

# Получить содержимое подпапки
GET /api/lab-photos?path=Физика/Механика
```

### React Component: `LabPhotoBrowser`

**File:** `components/LabPhotoBrowser.tsx`

**Props:**
```typescript
interface LabPhotoBrowserProps {
  onPhotosSelect?: (photos: string[]) => void  // Callback при выборе фотографий
  onPathChange?: (path: string) => void        // Callback при смене папки (опционально)
  locale?: 'ru' | 'ky'                          // Язык интерфейса
}
```

**Функции:**
- Иерархический просмотр папок с фотографиями
- Флажки для выбора отдельных фотографий
- Кнопка "Выбрать все" для быстрого выбора всех фото
- Кнопка "Отменить выбор" для снятия всех флажков
- Счётчик выбранных фотографий
- Поддержка русского и киргизского языков

## Интеграция в LabForm

Компонент `LabPhotoBrowser` интегрирован в форму создания лабораторной работы:

```tsx
<section className="admin-form-card">
  <div className="admin-form-section-title">{copy.sections.photos}</div>
  <p className="text-sm text-gray-600 mb-4">
    Выберите фотографии из доступных папок
  </p>
  <LabPhotoBrowser 
    onPhotosSelect={setSelectedPhotos}
    locale={locale}
  />
</section>
```

Выбранные фотографии сохраняются в состояние `selectedPhotos` и отправляются в форму как JSON:

```typescript
formData.set('photos', JSON.stringify(selectedPhotos))
```

## Безопасность

API endpoint включает защиту от path traversal атак:
- Проверяет, что конечный путь находится внутри `lab_photos/`
- Удаляет попытки использования `..` и `\`

## Пример использования

### Для администратора

1. Открыть форму создания лабораторной работы
2. Заполнить основную информацию (название, предмет, класс)
3. Перейти к разделу "Фотографии"
4. Развернуть необходимые папки (например, Физика → Механика)
5. Выбрать нужные фотографии с помощью флажков
6. Использовать кнопки "Выбрать все" / "Отменить выбор" для быстрого управления
7. Сохранить или опубликовать лабораторную работу

### Для разработчика

```tsx
import LabPhotoBrowser from '@/components/LabPhotoBrowser'

export function MyComponent() {
  const [selectedPhotos, setSelectedPhotos] = useState<string[]>([])

  return (
    <LabPhotoBrowser 
      onPhotosSelect={setSelectedPhotos}
      locale="ru"
    />
  )
}
```

## Проблемы и решения

### Проблема: API возвращает ошибку доступа к папке
**Решение:** Убедитесь, что папка `lab_photos/` существует и приложение имеет права на чтение

### Проблема: Фотографии не отображаются
**Решение:** Проверьте, что:
1. Файлы имеют правильное расширение (.jpg, .png и т.д.)
2. Файлы находятся в папке `lab_photos/`
3. Права доступа позволяют чтению файлов

### Проблема: Медленная загрузка при большом количестве фотографий
**Решение:** Организуйте фотографии в подпапки для лучшей навигации
